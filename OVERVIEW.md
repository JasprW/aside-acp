Unofficial community integration for Aside, not affiliated with or endorsed by Aside.

Use Aside's browser agent in Paseo with your local Aside account and browser profile. The provider exposes model, thinking effort and native permission choices, streams assistant replies and model reasoning, and resumes existing sessions.

Aside’s existing visible chats are available in Import Sessions, with title, directory and last activity. Import resumes the original Aside session and replays user, assistant and reasoning text. Choose Show all directories when the chat belongs to another directory. Discovery reads the local Aside session index with macOS’s SQLite CLI in read-only mode; no model turn is started.

Requires Paseo 0.11.2 and an installed, signed-in Aside CLI on the daemon machine. Aside's local macOS browser installation is required. Configure the account, default model and bridge behavior in `~/.aside-acp.json`, or select a config file with `ASIDE_ACP_CONFIG`.

The bridge reads Aside's model catalog and session transcripts from `~/.aside`, launches the Aside CLI and reads its live text/thinking event log, and stores session mappings in `~/.aside-acp/sessions`. Prompts and browser tasks run through your Aside account. No browser credentials are copied into Paseo.

Select Read only, Guard or Full access in Paseo's mode selector, and Ask first or Skip confirmation under Final confirm in session settings. Mode controls access boundaries; Final confirm controls send/pay/delete/submit confirmations. Guard defaults to Ask first, Read only disables final confirmation, and Full access preserves the selected choice. Skip confirmation does not bypass Guard. New bridge chats default to Ask first except Read only; `default_confirmation` configures this default.

The provider relays Aside's native file/tool approval and final-action suspension into Paseo's permission buttons and resolves the original paused request. Requests have identity/scope checks; cancellation and stale replies never authorize actions. Permanent grants are offered only for native permissions that support them. Draft/artifact data is included for review; screenshot artifacts are shown as metadata/path. Native questions appear during the task in Paseo's existing form, with single/multiple choices, multiple questions and custom text. Answers resume the original paused tool; dismissing rejects the question. Imported chats use the same relay, and questions answered in Aside are withdrawn from Paseo.

Both settings are saved and read from native sessions on import, reconnect and before tasks. Aside CLI's initial confirmation-off setting is corrected before sending the first task. Aside enforces native restrictions; final confirmation follows its own model/tool policy. The installed signed Aside CLI authenticates to the local daemon through a temporary loopback relay for its read-only account handshake. Tokens remain in memory, not plugin files; no Aside native module is loaded into Paseo. Requires Aside daemon 1.26.1011.1437 with suspension IDs and CLI 1.26.1010.1739 with raw events. Image prompts and MCP servers are unsupported. Browser tool calls are not individually rendered. Live event files are private and removed after the CLI exits; text and reasoning history are retained for replay.
